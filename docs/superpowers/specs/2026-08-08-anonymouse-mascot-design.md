# Anonymouse mascot — design

**Date:** 2026-08-08  
**Status:** approved for implementation

## Decision

One company mascot: **Anonymouse**. Two expressions of the same character:

| Version                            | Role                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| **Quiet Clever** (base / official) | Homepage-adjacent, about, proposals, OG, email footer, favicon simplification |
| **Friendly** (alternate)           | Social, stickers, merch, casual brand                                         |

Turtle / literal “Nothing” object / pixel CRT are **not** v1 mascot. Pixel terminal may remain a 404/easter asset only.

## Character system

- Small bipedal mouse; hood + ears must read at favicon size
- Palette: charcoal, soft violet accent, cream highlight — no neon, no storm sky
- Soft hoodie/jacket — **no cape, no lightning, no wet street, no giant chest `?`**
- Question mark as a **small pin or cursor** only
- Quiet Clever pose: calm stand; optional “shipped” stamp or checked clipboard
- Friendly: same body/props; only smile + wave (or peek)

## Usage rules

- Wordmark always outranks the mascot
- One prop language across channels
- Quiet Clever is the default in product UI

## Out of scope (v1)

- Turtle secondary mascot
- Favicon cut (can follow once silhouette is locked)
- Merch print files
