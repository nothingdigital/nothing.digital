## Defaults

| Service                      | Stack                                               |
| ---------------------------- | --------------------------------------------------- |
| Website                      | MSA + Fixed SOW                                     |
| Founding website             | MSA + Fixed SOW + Founding Addendum                 |
| Software / Apps / AI         | MSA + Discovery → Fixed SOW (+ AI Rider for AI)     |
| Email                        | MSA + Fixed SOW + Email Addendum (+ DPA if PII)     |
| Tech Literacy / Coding & SQL | Education CSA + Order (+ Minor Consent if under 19) |

## Rules

1. No work without signed SOW/Order (+ MSA or Education CSA).
2. Fixed quotes = written scope only; changes need Change Orders first.
3. Client owns ESP/cloud accounts; studio = role-based access.
4. Bespoke IP transfers only after full payment.
5. Education outcomes not guaranteed; parents contract for minors.

Fill `[BRACKETED]` fields. Store signed PDFs on the client record.
