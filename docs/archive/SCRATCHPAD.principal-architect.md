1. **Engineers** — CSP in app middleware (allow `analytics.nothing.digital` for `script-src`/`connect-src`). One file, no env.
2. **DevOps** — UptimeRobot monitors for `nothing.digital` + `/api/health`; keep free tier.
3. **DevOps** — Google Search Console + Bing verification + `/sitemap.xml` submission (already generated by Next.js?).
4. **QA** — Manual a11y pass; report findings as checklist in `docs/runbooks/a11y-manual-pass.md` or bug cards.
5. **QA + Engineers** — API integration tests for `/api/contact` and `/api/newsletter`; use test DB or seeded Supabase + mocked Resend/Listmonk.
6. **Engineers** — Only if a11y/API tests reveal shared defects; otherwise no code change.
7. **Defer** — n8n pod, Kuma, Lighthouse CI until unblocked/needed.

## Interfaces / contracts

### CSP (Engineers → DevOps)

- App ships CSP header in `middleware.ts`/`next.config`. DevOps later mirrors same policy in Cloudflare Transform Rules when domain migrates.
- Allowed hosts: `self`, `vercel.live`, `analytics.nothing.digital`, `*.supabase.co`, `*.sentry.io`. No wildcard for scripts.
- Umami script host comes from `NEXT_PUBLIC_UMAMI_SCRIPT_URL`; CSP can allow exact origin or `https://analytics.nothing.digital`.

### UptimeRobot (DevOps)

- Monitors: `https://nothing.digital` (200), `https://nothing.digital/api/health` (keyword `ok`).
- Alert target: owner email only (Slack later when alert budget exists).
- No code change required.

### Search engines (DevOps/Growth)

- Verify `nothing.digital` via DNS TXT or HTML file in `/public`.
- Submit `https://nothing.digital/sitemap.xml`.
- Bing uses same sitemap; no extra code.

### Manual a11y (QA → Engineers)

- Output: markdown checklist with pass/fail per page + screenshots/video for failures.
- Engineers fix only regressions or WCAG 2.1 AA violations; enhancements deferred.

### API integration tests (QA ↔ Engineers)

- Test target: `POST /api/contact`, `POST /api/newsletter`.
- Environment: `NODE_ENV=test` or dedicated Supabase project; mock Resend + Listmonk HTTP calls.
- Do not test rate-limiter timing (flaky); test shape and 201/400/429 responses.
- Shared setup lives in `src/lib/test/` if it does not exist; reuse existing Vitest config.

## Risk notes

- CSP in app + Cloudflare duplicate headers: ensure DevOps strips app CSP when Cloudflare policy active, or keep app as fallback.
- UptimeRobot free tier: 5-min intervals OK; do not pay for Pro unless incident proves need.
- Search console: verification can take 24–48 h; not a code blocker.
- API tests with real Resend/Listmonk: must mock; accidental email/campaign creation is bad.
- n8n deferred means Slack alerts not automated; UptimeRobot email + Sentry Slack enough for now.
